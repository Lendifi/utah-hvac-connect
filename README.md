# Utah HVAC Connect

Utah-only licensed HVAC lead matchmaker. Homeowners request a free quote; we match them with licensed Utah HVAC contractors.

**Live site:** https://utahhvacconnect.com

## Pages

- `index.html` — home
- `quote.html` — quote request form
- `for-contractors.html` — contractor info
- `privacy.html` — privacy policy
- `thanks.html` — post-submit thank you

## Lead form note

The quote form is **client-side only**. Submissions are not persisted to a backend yet (no lead storage or email delivery until that is wired up).

GitHub Pages from the `main` branch (root `/`), with custom domain `utahhvacconnect.com` (and www).
